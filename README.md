# AI 调料 RAG 评测项目

火锅底料风味/质量问题的**本地检索问答 + SPC 控制图**评测样例：语料入库后先检索出前五条证据，再由本地 7B 模型照着证据写答案；另含一组 24 批模拟数据的 SPC（I-MR）分析。全链路本地运行、不外发用户问题。

> 说明：本仓库只含**语料、评测脚本、题集、结果报告与文档**；本地模型（Ollama / qwen25-7b-local）、嵌入服务、SAG 命令行等运行依赖不在仓库内，需按下方「外部依赖」自行准备。

## 一、目录结构

| 目录 | 内容 |
| --- | --- |
| `01_knowledge_base/` | 初版语料：案例卡 CASE、文献卡 DOC、批次卡 TS |
| `01_knowledge_base_v2/` | 二版语料（补标题/措辞后），含导入说明 |
| `01_knowledge_base_v2_sag/` | 入库到 SAG Wiki 的定稿语料（含国标/企标/风味稳定性等口径卡） |

| `04_结果/` | 各轮评测逐题结果 CSV 与整批问答报告 |
| `05_数据体检/` | 数据事实清单与引用相关性抽查 |
| `06_修订版/` | 不覆盖原始列、只在新增列落改动的修订版数据 |

## 二、环境与外部依赖

### 1. Python 依赖

脚本用到 `jieba`、`openpyxl`、`pandas`（按需），建议在 Python 3.10+ 环境安装：

```bash
pip install jieba openpyxl pandas
```

### 2. 需配置的环境变量

脚本里仓库内路径已按相对路径推导；下列**仓库外的运行依赖**通过环境变量定位，缺省时会给出占位提示：

| 环境变量 | 指向 | 说明 |
| --- | --- | --- |
| `ZJ_TOOLS_DIR` | 外部工具目录（原 `_tools`） | 存放 SAG 命令行、重排缓存 JSON、外部日志 |
| `ZJ_SAG_BIN` | `sag.exe`（SAG Wiki 命令行）完整路径 | 检索决策服务可执行文件；未配置时脚本用占位字符串 |
| `ZJ_SOURCE_XLSX` | 原始数据整理 xlsx 路径 | 仅 `05_数据体检`、`06_修订版`、`_build` 建库脚本需要；仓库内不含原始 xlsx |

Windows PowerShell 示例（当前会话）：

```powershell
$env:ZJ_TOOLS_DIR   = "D:\path\tools"
$env:ZJ_SAG_BIN    = "D:\path\tools\sag\SAGWiki\bin\sag.exe"
$env:ZJ_SOURCE_XLSX = "D:\path\10.24数据整理.xlsx"
```

## 三、快速上手

> 以下命令均在 `03_评测/` 目录下执行；路径用相对仓库根的写法。

### 1. 一键自检（推荐先跑）

```bash
python 99_验收自检.py            # 完整自检（约 1~2 分钟）
python 99_验收自检.py --fast     # 跳过 30 题整批问答
```

断言的是能力底线：两端口在线、索引片数、术语/口语 Hit@1 下限、零召回为 0、水分口径与黑水题归因正确、30 题整批全命中；任一不达标即退出码 1 并指出哪一条。

### 2. 分项复现

| 目的 | 命令 |
| --- | --- |
| 检索指标（K=2） | `python 09_sag2_syn_eval.py 2` |
| 重排权重网格 | `python 15b_rerank_grid.py` |
| 防过拟合（30 题 × 四方案） | `python 15c_30q_check.py` |
| 闸门验证 | 先删外部目录下 `rerank_cache_30.json`，再 `python 15d_gate_check.py` |
| 单题问答 | `python 11_local_answer.py "问题"` |
| 30 题整批 | `python 12b_answer_batch_30.py` |

### 3. 本地问答界面

启动 Ollama、决策服务、嵌入服务后，运行：

```bash
python ui_server.py
```

浏览器打开 `http://127.0.0.1:8600`，页面给出答案、前五证据与触发规则标签。

## 四、关键评测口径（结论以 `00`、`08`、`19` 为准）

- 语料 **120 片 / 257 chunk / 4424 词表**；最优配置为纯词法决策 + M1 总是扩词 + K=2，重排 `alpha=0.65`。
- 30 题固定集术语 Hit@1 93.3%、口语 86.7%，零召回 0；30 题整批问答 30/30。
- **数据性质**：24 批为基于文献区间构建的**模拟数据集（非企业真实台账）**。
- **水分口径**：参照 GB/T 45662-2025 表 1、无内控不判定；先说"不判定"再给参照值。
- **SPC 结论**：合格不等于受控；数据呈两月一次的成段整体抬升，属过程漂移，单点剔除是错误修正方法。

## 五、边界与已知限制

- 7B 会把代理指标讲成实测指标；三选五时可能漏最对症证据（靠归因规则补救）。
- 分层控制限、EWMA、管理类原话归类、实词级匹配等已识别但未实施。
- SAG 自带桌面问答页不适合作为小模型 agent 前端（模型会把工具调用写坏）；替代方案是 `ui_server.py` 检索先行链路。

## 六、复现/交接注意

- 原始企业数据 xlsx 不在仓库；需要重建案例/批次卡时，先配置 `ZJ_SOURCE_XLSX`。
- `01_knowledge_base_v2_sag/` 是入库定稿语料，检索/问答脚本默认读它。
- 历史报告在 `_归档_历史报告_20261107/`，其中指标是旧语料规模下的读数，不要混引。
