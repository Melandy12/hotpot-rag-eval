# v1 → v2 知识库对照（同一题集、同一脚本，只换语料）

## 结论先说

**换语料让口语版的 Hit@1 从 86.7% 提到 93.3%，MRR 从 0.922 提到 0.956，零召回仍然是 0。**

这说明一件很重要的事：**提升不一定来自算法，也可能来自把语料本身变"可检索"。** 这次一个算法参数都没动，只是把修订版里的判定限值、产品编码补进分片文本，C 组就涨了 6.6 个百分点。

## 实测数字

| 方案 | 问法 | v1 Hit@1 | v2 Hit@1 | v1 MRR | v2 MRR | 零召回 |
|---|---|---|---|---|---|---|
| A 纯 BM25 | 术语版 | 100.0% | 100.0% | 1.000 | 1.000 | 0 → 0 |
| A 纯 BM25 | 口语版 | 26.7% | 26.7% | 0.313 | 0.313 | 9 → 9 |
| B ＋领域词典 | 术语版 | 93.3% | 93.3% | 0.967 | 0.967 | 0 → 0 |
| B ＋领域词典 | 口语版 | 26.7% | 26.7% | 0.313 | 0.313 | 9 → 9 |
| C ＋同义词扩展 | 术语版 | 86.7% | 86.7% | 0.933 | 0.933 | 0 → 0 |
| C ＋同义词扩展 | 口语版 | 86.7% | **93.3%** | 0.922 | **0.956** | 0 → 0 |

Hit@3 / Hit@5 三组六行全部 100%，没有变化。

## 为什么会长

v2 只改了三处语料：

1. **时序卡新增「判定限值」段**：`酸价 2.5 mg/g`、`过氧化值 0.25 g/100g` 加出处。原来这些数字只散落在案例正文里，现在成了分片里能被检索到的结构化内容。
2. **案例卡新增「产品编码」字段**：`PRD-01` 这类编码进来后，同产品的案例之间多了一层可匹配信号。
3. **案例卡「来源记录」换成修订版**：清掉 22 条错引后，某些分片不再被错误文献的标题词"带偏"。

**注意逻辑**：A 组和 B 组的口语版一个数字都没动（26.7% / MRR 0.313 / 零召回 9）。这是正常的——A 组没有同义词扩展，无论语料怎么改，那 9 题的口语词和语料词项仍然零交集，**空集上加什么语料还是空集**。这反过来再次验证了之前的诊断：**口语零召回的病因是词表，不是语料量，也不是分词。**

## 唯一一个没修好的点

「风味稳定性」口语题（"底料放两个月就不香了 味道跑掉了"）仍然只排到第 3：

```
CASE-2026-019 > DOC-042 > DOC-013 > DOC-008 > CASE-2026-004
```

期望的 DOC-013（讲风味物质变化）被 DOC-042 压了一头。这是**同义词扩展的副作用**：`味道跑掉 → 挥发性风味物质` 这条映射把"挥发性风味物质"收成整词后，DOC-042 里出现得更密，反而挤掉了 DOC-013。

修法（下一轮做）：**扩展词降权 0.5**，或者只做"现象→指标名"单向映射，不再往"指标→更多指标"扩散。
