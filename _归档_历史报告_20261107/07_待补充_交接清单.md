## 一、最优先：20~25 个批次的出厂检验数据

**为什么必须有**：现在时序表是"一个批次在不同储藏天数下的变化"，每个组合只有 3~4 个点，而且同一批的酸价必然随储藏时间上升。这种数据画控制图会 100% 判"过程失控"，是伪信号。**没有这批数据，项目的 SPC 模块就是假的。**

| 项 | 内容 |
|---|---|
| 谁做 | 能拿到检验台账的人（找老师/车间/品控要） |
| 具体动作 | 取**同一个产品、同一个指标、同一个检测时点（出厂/0 天）**连续 20~25 个批次的值 |
| 最省事版本 | 1 个产品 × 1 个指标 × 20 个批次（如"牛油麻辣底料 出厂酸价"20 个值） |
| 完整版本 | 2 个产品 × 2 个指标（酸价、过氧化值）× 25 个批次 |
| 交付格式 | 按 `05_数据体检\05_SPC数据模板.csv` 的表头填，**一列都不要删** |
| 必须有的列 | 产品编码、批次号、生产日期、检测时点_天、指标名称、实测值、单位、平行样1/2/3、检测方法、仪器编号、操作人、判定限值 |
| 合格标准 | ① 行数 ≥ 20 ② 批次号不重复 ③ 同一产品同一指标 ④ 检测时点一致 ⑤ 实测值不为空 |
| 预估工时 | 2~3 小时（台账是 Excel 的话，主要是整理格式） |
| 给不了怎么办 | 有多少给多少，并在备注列写"仅 N 个批次，控制限为初始估计" |

## 十、数据填好之后怎么跑（不用问我）

第 1 项的数据按模板填完后，直接执行：

```
python 06_修订版\07_run_imr_control.py --file 05_数据体检\05_SPC数据模板.csv --product PRD-01 --indicator 酸价 --timepoint 0
```

会输出中心线 X̄、MR̄、σ 估计、UCL/LCL、逐点 Nelson 判异，并存成 `05_SPC数据模板_IMR结果.csv`。

脚本内置三道保护：**点数 <8 直接拒绝计算**（现在拿模板跑就是这个结果）、**点数 <20 自动标注"控制限为初始估计"**、**不认识的限值自动跳过不判**。所以不用担心填错会算出一堆假结果。
