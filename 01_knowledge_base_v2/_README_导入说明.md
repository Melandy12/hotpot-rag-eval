# 知识库 v2 导入说明

## 这份是什么

106 个 Markdown 分片 + `_manifest.csv`，用**修订版数据**重建：案例卡片的来源记录已换成修订版（清掉 22 条错引），案例卡补了产品编码，时序卡补了判定限值与出处。

## 导入 Cherry Studio

1. 打开 Cherry Studio → 左侧「知识库」→ 新建
2. 名称填 `调料风味稳定性_v2`
3. 选择「文件夹导入」，指向 `01_knowledge_base_v2` 整个目录
4. 勾选全部 106 个 `.md`（`_manifest.csv` 不用导入，它是给脚本用的）

⚠ **重要前提**：Cherry Studio 的知识库是**向量检索**，必须先指定 embedding 模型才能建索引和搜索。也就是说——

> **在 Cherry Studio 里做不到"不配嵌入跑 BM25"。** BM25 只存在于我们自己的脚本里。

所以原来的"平台内 BM25 基线数字"这个目标要改写为：
- **脚本侧**给 BM25 的数字（已有：术语版 100%、口语版 93.3%）
- **平台侧**只能在配了 embedding 之后给向量/混合检索的数字

这不影响结论，只是要跟评审说清楚：**BM25 是我们做的检索算法验证，Cherry Studio 是我们做的落地载体，两者不是同一层**。

## 导入 AnythingLLM

1. Workspace 新建 → 名称 `调料风味稳定性_v2`
2. 上传文档 → 选 `01_knowledge_base_v2` 全目录
3. Embedder 选 `bge-m3` 或 `nomic-embed-text`（AnythingLLM 内置支持，不用另装 Ollama）
4. Vector DB 用默认 LanceDB 即可
