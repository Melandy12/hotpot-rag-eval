# CASE-2026-001｜牛油麻辣底料（BATCH-26-001）｜开袋后闻到明显哈喇味，表面油脂颜色发暗变深

| 字段 | 内容 |
|---|---|
| 案例编号 | CASE-2026-001 |
| 产品编码 | PRD-01 |
| 产品及批次 | 牛油麻辣底料（BATCH-26-001） |
| 异常现象 | 开袋后闻到明显哈喇味，表面油脂颜色发暗变深 |
| 发生时间及储藏条件 | 2026年4月 常温25℃储藏90天 |
| SPC指标表现 | 酸价连续突破2.5mg/g上限达到2.6mg/g；过氧化值逼近限值达到0.27g/100g |
| 调查确认的原因 | 夏季炒制温度未随环境调整长时间高温（>165℃）导致牛油提前氧化；且原包装透氧率过高 |
| 采取的措施 | 优化炒制曲线降温至145℃；更换为高阻隔铝箔包装袋 |
| 措施后的结果 | 后续批次在同等储藏条件下保质期内酸价未超标 |
| 来源记录 | 《一种降低红油火锅底料油脂酸价的炒制工艺》（DOC-005） |
| 原因状态 | 已确认 |
