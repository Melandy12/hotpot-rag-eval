# CASE-2026-002｜番茄底料（BATCH-26-004）｜产品在货架期内出现胀袋，且颜色发暗

| 字段 | 内容 |
|---|---|
| 案例编号 | CASE-2026-002 |
| 产品编码 | PRD-03 |
| 产品及批次 | 番茄底料（BATCH-26-004） |
| 异常现象 | 产品在货架期内出现胀袋，且颜色发暗 |
| 发生时间及储藏条件 | 2026年7月 夏季高温运输（35℃） |
| SPC指标表现 | 菌落总数超标pH值异常下降0.5 |
| 调查确认的原因 | 夏季物流车厢温度过高番茄酱水分活度高导致乳酸菌繁殖；番茄红素见光降解导致变色 |
| 采取的措施 | 调整山梨酸钾比例至0.8g/kg改用冷链运输；更换不透光包装材料 |
| 措施后的结果 | 胀袋率由3%降至0.1%以内颜色保持期延长2个月 |
| 来源记录 | 《番茄火锅底料在贮藏期的品质变化规律》（DOC-021） |
| 原因状态 | 已确认 |
