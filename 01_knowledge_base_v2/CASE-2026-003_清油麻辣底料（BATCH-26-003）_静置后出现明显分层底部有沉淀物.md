# CASE-2026-003｜清油麻辣底料（BATCH-26-003）｜静置后出现明显分层底部有沉淀物

| 字段 | 内容 |
|---|---|
| 案例编号 | CASE-2026-003 |
| 产品编码 | PRD-02 |
| 产品及批次 | 清油麻辣底料（BATCH-26-003） |
| 异常现象 | 静置后出现明显分层底部有沉淀物 |
| 发生时间及储藏条件 | 2026年5月 常温储藏30天 |
| SPC指标表现 | 油脂析出率＞5%乳化稳定性下降 |
| 调查确认的原因 | 菜籽油与豆瓣酱的乳化工艺不彻底缺少高压均质环节 |
| 采取的措施 | 引入高压均质机处理增加单甘脂乳化剂比例 |
| 措施后的结果 | 分层现象消除组织状态均匀 |
| 来源记录 | 《红汤火锅底料参数优化设计》（DOC-003） |
