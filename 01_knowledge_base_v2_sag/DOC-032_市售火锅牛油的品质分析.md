# 市售火锅牛油的品质分析

- 作者：马国丽、王俏君、王冲、吴港城、金俊、张逸仙（广汉市迈德乐食品 / 江南大学食品学院）

## 核心提取内容（供AI检索）

52 个市售牛油样品跨 6 省；水分及挥发物均 <0.1%；熔点 42~46℃；酸价地区排序；吉林与山东塑化剂超标；饱和脂肪酸 >50%；四川重庆共有 8 种关键风味物质

## 关键数据（来自期刊摘要）

**样品**：四川、重庆、内蒙古、吉林、山东、河北共 **52 个市售牛油样品**。

| 指标 | 结果 |
|---|---|
| 颜色深浅 | 山东 > 内蒙古 > 重庆 > 吉林 > 河北 > 四川 |
| 熔点 | 42~46℃，**无显著差异** |
| 水分及挥发物 | **均 <0.1%** |
| 酸价 | 均符合国标规范限值；高低排序 **吉林 > 内蒙古 > 重庆 > 山东 > 河北 > 四川** |
| 过氧化值 | 均符合国标限值，无显著差异 |
| 塑化剂 | **吉林和山东样品平均含量超标** |
| 脂肪酸 | 无显著差异；饱和脂肪酸 **>50%**，不饱和脂肪酸 36%~42% |
| 风味 | 四川、重庆样品共有 8 种关键风味物质；膻香味无差异；重庆样品的脂香、烤香、清新味浓于四川 |

## 对本项目的意义

1. **牛油原料的行业实测基线**：水分及挥发物 <0.1%、熔点 42~46℃、酸价全部合格——可以据此判断，若进厂牛油水分超过 0.1% 或酸价不合格，属于供应商问题而非工艺问题；
2. **地区差异可用于供应商分级**：虽同为合格，但酸价排序（吉林 > 内蒙古 > 重庆 > 山东 > 河北 > 四川）提示不同产地来料风险不同，可作为"卡严供应商"的量化依据；
3. **塑化剂风险**：吉林、山东样品超标，对应本项目 CASE-2026-014（塑化剂检出）与 DOC-018（DBP 超标率 65.22%），三条互证说明塑化剂是行业性问题而非个案；
4. 该文与 DOC-018 出自同一研究团队（广汉迈德乐 / 四川牛油加工工程技术研究中心），可连成"原料—成品"一条证据链。
