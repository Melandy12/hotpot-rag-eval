# 牛油精炼工艺的研究

- 文档编号：DOC-030（新增）
- 来源：《食品工业科技》2007 年第 4 期
- 原文链接（全文 PDF，期刊在线公开）：http://www.spgykj.com/cn/article/pdf/preview/SPKJ200704048.pdf

## 核心提取内容（供AI检索）

牛油精炼 水化（脱胶）→ 碱炼（脱酸）→ 脱色 → 脱臭；加碱量 = 0.715×酸价；脱臭 140℃/10mmHg/30min；精炼后酸价 ≤0.5 mgKOH/g；水分及挥发物 ≤0.5%；熔点 42~46℃

## 工艺流程（原文）

粗牛油 → 熔油 → 过滤 → 水化 → 碱炼 → 脱色 → 过滤 → 脱臭 → 注模 → 冷却 → 脱模 → 精炼牛油块 → 包装 → 成品

## 关键参数（逐条可核验）

| 工序 | 参数 |
|---|---|
| 水化（脱磷/脱胶） | 油温 90℃；喷入油量 6% 的 80~90℃ 热水；再加 0.1% 食盐；缓慢搅拌至细小胶粒析出；静置分层放水脚，**反复 2 次** |
| 碱炼（脱酸，关键步骤） | 碱液浓度 0.2%；碱炼温度 **70~80℃**（比油脂凝固点高 20~25℃）；搅拌先快后慢 **50→20 r/min**；加 0.3% 稀盐水（浓度 0.4%）助皂脚沉降 |
| 理论加碱量 | =(酸价×40)/56 = **0.714×酸价**（kg/t） |
| 实际加碱量 | 超量 0.2% → 1.002×0.714×酸价 = **0.715×酸价** |
| 脱色 | 活性白土用量 5%；油温 91℃；抽真空 600mmHg 20 min；升温 105℃ 保持 20 min；冷却至 60℃ 压滤 |
| 脱臭 | 温度 **140℃**、真空 **10 mmHg**、时间 **30 min**，冷却 60℃ 后注模 |

## 精炼后质量指标（原文）

| 指标 | 值 |
|---|---|
| 酸价 | **≤0.5 mgKOH/g** |
| 过氧化值 | ≤0.15% |
| 水分及挥发物 | ≤0.5% |
| 熔点 | 42~46℃ |
| 外观 | 乳白色、纯正、无异味、无杂质 |

## 机理表述（可直接引用）

- 粗牛油因贮存时间与环境影响，部分被分解成**游离脂肪酸和甘油**，不饱和甘油脂被氧化成**醛和低分子酸等恶臭物质**，故必须精炼除去酸性物质与杂质；
- 水化加水量不足则沉淀不完全，加水过多则蛋白质乳化难分离；
- 碱炼温度不宜过高否则中性油皂化，加碱量过大易发干、过细难分离；
- 脱臭在真空下进行，既降低臭味组分沸点、减少高温对营养的破坏，又防止热油被大气氧化；甘油酯在 120~160℃、1~10mmHg 下不挥发，可只带走挥发性臭味物质。

## 对本项目的意义

**直接补上“精炼 vs 火炼”这个语料缺口。** 车间师傅说“牛油不买火炼的、买精炼的”，指的是**火炼（直接加热炼制、只熔油过滤）没有碱炼脱酸这一步，精炼多一道碱炼能把游离脂肪酸中和掉**，所以精炼牛油酸价可以做到 ≤0.5，火炼牛油则基本保留原料酸价水平。这条把“原料酸价为什么能卡严”讲通了，也解释了为什么验收要按原料端 GB 10146 的 2.5 而不是成品的 4.0。
