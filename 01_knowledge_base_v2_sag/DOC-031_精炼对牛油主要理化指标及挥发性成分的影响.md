# 精炼对牛油主要理化指标及挥发性成分的影响

- 文档编号：DOC-031（新增）
- 来源：《食品与机械》2020 年第 4 期，62-67 页
- 作者：刘佳敏、何新益、刘晓东、闫西纯、廖振宇（天津农学院 / 天津市农副产品深加工技术工程中心 / 天津伊兴清真食品 / 谱尼测试天津）
- 原文链接：http://m.qikan.cqvip.com/Article/ArticleDetail?id=7101919140

## 核心提取内容（供AI检索）

精炼各阶段牛油酸价先降后升、过氧化值递增、碘值递减；精炼后酸价 0.37 mg/g、过氧化值 0.0575 g/100g、碘值 12.47 g/100g；16 种脂肪酸；脱酸后醛类最高、脱色后降低、酯类逐渐增多

## 关键结论（来自期刊摘要）

**测定阶段**：熔油 → 脱酸 → 脱色，逐阶段测酸价、过氧化值、碘值、脂肪酸、挥发性成分。

**趋势（原文表述）**：
- **酸价：先降后升**（脱酸段因碱炼中和游离脂肪酸显著下降，后续阶段因氧化与残留脂肪酸回升）
- **过氧化值：递增**（精炼过程中持续上升，说明精炼并非"越精越稳"，氧化在推进）
- **碘值：递减**（不饱和度下降）

**精炼成品指标**：酸价 **0.37 mg/g**、过氧化值 **0.0575 g/100g**、碘值 12.47 g/100g。

**脂肪酸**：精炼各阶段均含 16 种脂肪酸，主要为**油酸、棕榈酸、硬脂酸**。

**挥发性成分（气相—离子迁移谱）**：
- 醇类物质在精炼过程中**逐渐减少**；
- **脱酸后醛类达到最高值**；
- 脱色后成品中醛类**有所降低**；
- 酯类在精炼过程中**逐渐增多**。

## 对本项目的意义

1. 与 DOC-030 互为印证：**精炼能把酸价压到 0.37 mg/g**，远低于 GB 10146 的 2.5，这是"买精炼牛油"的定量理由；
2. 但**过氧化值在精炼过程中递增**，说明"精炼≠全面更稳定"——验收不能只看酸价，必须酸价与过氧化值同时看，这一条正好对应本项目 CASE-2026-001 与过氧化值联动判定；
3. 醛类在脱酸段最高、脱色后降低，可作为"苦味/哈喇味来自哪一段"的解释依据。
