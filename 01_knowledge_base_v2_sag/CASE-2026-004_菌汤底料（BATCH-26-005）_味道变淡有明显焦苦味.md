# CASE-2026-004｜菌汤底料（BATCH-26-005）｜现象：味道变淡有明显焦苦味｜原因：储存环境湿度大菌菇粉吸潮结块｜措施：使用铝箔袋独立小包装

| 字段 | 内容 |
|---|---|
| 案例编号 | CASE-2026-004 |
| 产品编码 | PRD-04 |
| 产品及批次 | 菌汤底料（BATCH-26-005） |
| 异常现象 | 味道变淡有明显焦苦味 |
| 发生时间及储藏条件 | 2026年6月 高温高湿环境 |
| SPC指标表现 | 氨基酸态氮含量显著下降 |
| 调查确认的原因 | 储存环境湿度大菌菇粉吸潮结块；灭菌温度过高导致美拉德反应过度 |
| 采取的措施 | 使用铝箔袋独立小包装；控制灭菌温度≤115℃ |
| 措施后的结果 | 风味保留率提升至95%以上 |
| 来源记录 | 《火锅底料香气提升研究进展》（DOC-008）（间接参考） |
| 原因状态 | 已确认 |
