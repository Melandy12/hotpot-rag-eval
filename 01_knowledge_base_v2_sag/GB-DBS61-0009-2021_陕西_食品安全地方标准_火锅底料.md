# DBS61/0009-2021 食品安全地方标准 火锅底料（陕西）

- 文档类型：食品安全地方标准（陕西，强制性）
- 标准编号：DBS 61/0009-2021，代替 DBS 61/0009-2016
- 发布/实施：2021-12-14 发布，2022-06-14 实施
- 发布机构：陕西省卫生健康委员会
- 原文出处（政府公开 PDF，已核）：
  https://sxwjw.shaanxi.gov.cn/sy/tzgg/202112/P020211216374809221576.pdf

## 核心提取内容（供AI检索）

酸价 ≤3.0 mg/g（配料含豆瓣酱不超 4.0）；过氧化值 ≤0.25 g/100g；总固形物 ≥30.0 g/100g（仅清汤火锅底料）；附录 A 总固形物测定方法；固态底料总砷/铅限量更宽

## 分类（第 3 章）

- 按常温形态：液态 / 半固态 / 固态火锅底料
- 按包装类型：单一包装 / 组合包装火锅底料
- 术语：清汤火锅底料指以畜禽肉骨、水、食用盐、香辛料、酱类等为原料，**较少使用麻辣料和食用油**的液态底料，如番茄、菌菇火锅底料

## 理化指标（表 2，原文）

| 项目 | 指标 | 检验方法 |
|---|---|---|
| 酸价（以脂肪计）(KOH)/(mg/g) ≤ | **3.0**（注 a：配料含**豆瓣酱**时不应超过 **4.0**） | GB 5009.229 |
| 过氧化值（以脂肪计）/(g/100g) ≤ | **0.25** | GB 5009.227 |
| 亚硝酸盐（以 NO₂⁻ 计）/(mg/kg) ≤ | 10（仅适用于含腌渍蔬菜的底料） | GB 5009.33 |
| 总砷/(mg/kg) ≤ | 液态 0.1 / 半固态 0.2 / 固态 0.4 | GB 5009.11 |
| 铅/(mg/kg) ≤ | 液态 0.1 / 半固态 0.2 / 固态 0.5 | GB 5009.12 |
| 黄曲霉毒素 B₁/(μg/kg) ≤ | 5.0 | GB 5009.22 |
| **总固形物/(g/100g) ≥** | **30.0（仅适用于清汤火锅底料）** | **附录 A** |

注 a：酸价不适用于配料含食醋、酸味调节剂的火锅底料。

## 附录 A：总固形物的测定（规范性）

- 试样 5~10 g（精确至 0.0001 g），置于已恒重并盛海砂的称量皿
- 水浴上蒸干 → 擦干 → 101~105℃ 烘 2 h → 干燥器冷却 30 min 称量 → 复烘至恒重
- 计算：X =(m₁−m₂)/m ×100（g/100g），保留一位小数
- 精密度：两次独立测定绝对差值不超过算术平均值的 **10%**
- 组合包装取样：干制蔬菜包、干菌菇包等全部料包倒入组织捣碎机捣碎混匀后取样

## 对本项目的意义

1. **“总固形物”终于有出处和测定方法**。此前“氨基酸态氮和总固形物”一题零召回、语料里根本没这个词，现在是可引用的条款 + 可复现的检测方法（附录 A），能直接支撑料渣/固形物类问题的回答。
2. **酸价 3.0 与 4.0 的关系讲清了**：陕西地标基准 3.0，但**配料含豆瓣酱可放宽到 4.0**——火锅底料普遍含豆瓣酱，这解释了为什么行业里 4.0 更常见。重庆地标则直接定 4.0。
3. 提示本项目：判定限值时必须同时说明“标准属地 + 是否含豆瓣酱”，只说数字必被追问。
