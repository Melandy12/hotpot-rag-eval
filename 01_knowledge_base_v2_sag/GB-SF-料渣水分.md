# 料渣水分

- 文档编号：GB-SF-料渣水分（自建概念卡）
- 一句话：火锅底料的水分几乎全在**渣相**里，油相可以忽略，所以"水分"实质是"料渣含水量"。
- **本卡只讲概念、测定与判定口径**；具体现象的成因与整改看对应案例卡，不在这里复述。

## 一、两相结构

火锅底料 = 油相 + 渣相。

| 相 | 组成 | 含水水平 |
|---|---|---|
| 渣相 | 辣椒、花椒、豆瓣酱、姜蒜、香辛料、肉粒的残渣 | **产品的主体** |
| 油相 | 牛油／植物油 | 极低：52 个市售牛油样品"水分及挥发物"**均 <0.1%**（DOC-032） |

→ 底料"水分 30%"说的就是渣相含 30% 水。无渣型产品的渣相少，该值天然更低（QY-企业标准样例_广汉佳越立德 分含渣型/无渣型）。

## 二、渣相偏高会连带什么（只列方向，细节在别的卡）

1. **酸价同向上升**。DOC-019 逐点数据：4℃ 冷藏 60 天，0.1208% → 0.2389%，酸价 1.71 → 1.96 mg/g；后 20 天酸价涨 0.13、过氧化值涨 0.00149，是前 20 天的 3 倍以上。
2. **加热后易起沫变色**。机制与整改过程见 CASE-2026-035（结论：底料混入水；措施：炒制后真空脱水；结果：现象消除）。
3. **微生物风险**。Q/NHTY 0019S—2019 对大肠菌群限量 n=5、c=2、m=10、M=100 CFU/g。

## 三、测定方法

- 依据 **GB 5009.3-2016 第一法（直接干燥法）**：101~105℃ 干燥至恒重，两次称量差 ≤2 mg。
- **取样必须均质**：油相 <0.1%、渣相 20~30%，同一锅挖两勺能差一个数量级。建议 60~65℃ 水浴融化搅匀后称样。
- 平行样两份，超差重做。
- 记录必带：**取样温度、均质方式、称样量**——缺任一项，两个水分数不可比。

## 四、判定口径

| 情形 | 如何处理 |
|---|---|
| 有企业内控文件 | 按内控线判，写明文件编号与条款 |
| 无内控文件 | **输出"限值未核定（不判定）"**，不拿国标硬判 |
| 需参照值 | 只引 GB/T 45662-2025 表 1（固体 ≤25 / 半固体 ≤50 / 液态 ≤60），并注明该标准 2026-06-01 实施、数据在其之前，属"参照" |

**注意**：Q/NHTY 0019S—2019 表 2 不设水分，只有酸价（油膏包 3.0）与过氧化值 0.25。故"水分 30% 是本公司限值"无文件支撑。

**本项目唯一一组水分数据**：BATCH-26-006（牛油特辣底料，25℃，90 天）：12.5% → 11.8% → 11.2% → 10.8%，逐点下降。**这组数据只作参照、不作判定**：一是 GB/T 45662-2025 于 2026-06-01 才实施，数据在其之前；二是没有企业内控文件。口径固定为"参照 GB/T 45662 表 1（半固体 ≤50），无内控不判定"。要留意的是**水分下降本身说明密封/挥发在起作用**，与"料渣偏湿"是两回事，别把它当渣相含水率。

## 五、缺口

1. 企业水分内控线（无文件）。
2. 渣相含水率实测值（现有数据只有产品水分限值与牛油水分 <0.1%，无渣相单独测定值，不能估）。
3. 含渣型 / 无渣型的分产品线水分基线。
