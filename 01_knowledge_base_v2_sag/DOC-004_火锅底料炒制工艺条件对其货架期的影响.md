# 火锅底料炒制工艺条件对其货架期的影响

- 文档编号：DOC-004
- 来源：《食品科学》2016 年第 17 期，84-89 页（EI/CSCD）
- 作者：王强、王睿、熊政委、任彦荣、宋帧伟（重庆市功能性食品协同创新中心 / 重庆第二师范学院 / 重庆德庄农产品开发有限公司）
- 原文链接（全文 PDF）：https://files.sciengine.com/pdfs/1002-6630/F1589D0BF4C1425EA911EDAE1DB87C6A.pdf

## 核心提取内容（供AI检索）

炒制温度 140℃ 以上油脂氧化明显加快；140℃ 时 UFA/SFA 下降 13.1%；0.1~0.5MPa 低压抑制油脂水解氧化；温度升高货架期缩短；加热面积对氧化无显著影响

## 关键数据与结论（可核验，来自全文）

| 变量 | 结果 |
|---|---|
| 温度 80~120℃ | UFA/SFA 总体无明显变化 |
| 温度升至 140℃ | UFA/SFA 较 120℃ **下降 13.1%**，POV、TBARS、AV 三个氧化指标均明显升高 |
| 温度 160~180℃ | 氧化速率相对平稳，但持续高温导致反式脂肪酸增加 |
| 压力 0.1~0.5MPa（低压） | **可抑制油脂水解氧化**，氧化指标随压力升高而下降，反式脂肪酸下降 13% |
| 压力 >100MPa（超高压） | 氧化速率明显加快，货架期较常压**缩短 26%** |
| 加热面积 17%~45% | 对氧化指标、脂肪酸组成、货架期**均无显著影响** |

**全文核心句**：温度高于 140℃ 时氧化反应速率明显加快，尤其 140℃ 以上油脂氧化程度显著加深；温度与压力是主控因子，加热面积不是。

**工艺基线（该研究的底料做法）**：植物油中加草果、豆瓣酱、生姜、丁香、桂皮、八角、盐、胡椒、豆蔻、料酒炒 4~10 min；牛油加热融化后加辣椒、花椒、鸡精、冰糖炒 4~10 min；混合后熬 2~5 min；冷却、密封、灭菌。

**对本项目的意义**：这是当前语料中唯一给出“温度阈值 + 定量幅度”的工艺文献，是 SPC 判定酸价漂移后归因到炒制温度的直接依据；本项目 2 月、4 月出现的两个酸价峰（2.3、2.4 mg/g），可对照本条判断现场是否出现 140℃ 以上的超温时段。
