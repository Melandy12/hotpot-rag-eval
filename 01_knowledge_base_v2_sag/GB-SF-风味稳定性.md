# 风味稳定性

- 文档编号：GB-SF-风味稳定性（自建概念卡）
- 一句话：**风味稳定性 = 货架期内"香气与滋味不显著偏离出厂状态"的能力**，可拆成"挥发性成分的种类与含量、特征香气保留率、间接理化指标"三层来测。
- **本卡只讲概念、指标与判定口径**；具体某次"不香了/哈喇味"的成因与整改看对应案例卡，不在这里复述。

## 一、三层指标体系

| 层 | 测什么 | 手段 | 本项目有没有数据 |
|---|---|---|---|
| ① 成分层 | 挥发性风味物质的种类与相对含量（萜烯类、醛类、酯类、醇类） | GC-MS / GC-IMS / 电子鼻 | **没有** |
| ② 特征层 | **香气保留率**：某时点关键成分含量 ÷ 出厂时含量 | 同上，定点跟踪 | **没有** |
| ③ 理化层（代理） | 酸价、过氧化值、水分及挥发物 | GB 5009.229 / 5009.227 / 5009.3 | **有**（24 批 + 3 条储藏时序） |

**口径必须写清**：本项目 24 批只有 ③，没有 ①②。所以本项目谈"风味稳定性"时，**③ 只能作为代理指标**，不能声称测过香气保留率。

## 二、该盯的关键成分（DOC-018，23 个重庆牛油方砖样品）

- 共检出 **111 种**挥发性成分，**萜烯类含量最高**；
- **16 种为关键挥发性成分**：桉叶油醇、β-水芹烯、异戊醛、4-烯丙基苯甲醚、月桂烯、4-烯丙基-2-甲氧基苯酚、芳樟醇等；
- 其中 **桉叶油醇、β-水芹烯、异戊醛**是 23 个样品**共有**的，可作"必备风味指纹"；
- **4-烯丙基苯甲醚、月桂烯、4-烯丙基-2-甲氧基苯酚、芳樟醇**为**差异性**成分，是"配方/原料波动"最容易露头的地方。

→ 做"香气保留率"就按这 16 个算，尤其先看三只共有的。**没有这 16 个成分的实测数据，就不要算保留率。**

## 三、衰减是怎么发生的（只列方向，数字见对应卡）

1. **氧化后段加速**。DOC-019：4℃ 冷藏 60 天，前/中/后各 20 天酸价分别 +0.04 / +0.08 / **+0.13** mg/g，过氧化值 +0.00039 / +0.00053 / **+0.00149**——后段涨幅是前段 3 倍以上，原文归因为"从诱导期进入氧化期，过氧化物再分解为醇类和羧基化合物"。
2. **精炼阶段就把醛类推高了**。DOC-031：脱酸后**醛类最高**、脱色后降低、酯类逐渐增多、醇类逐渐减少——所以"苦味/哈喇味"要区分是原料带来还是某一段工艺带来。
3. **辣椒素类物质同步下降**。DOC-019：辣椒素类似物前/中/后各 20 天分别下降 0.976% / 0.976% / **0.732%**——辣度衰减与香气衰减不是同一条曲线。
4. **行业现状本身就散**。DOC-018：23 个同品类市售样品的**感官香气、酸值、过氧化值、熔点均存在显著差异**。

## 四、怎么评价

- **建模法**（DOC-013）：用主成分分析（PCA）把挥发性成分压成少数几个主成分再做评价——该文 B 端 154 种 / C 端 158 种风味物质，**7 个主成分累积方差 100%**，模型与**感官评价的相关系数 0.908**。也就是"成分数据 → 感官分数"这条路是走得通的，可以替代一部分人工品评。
- **对比法**（DOC-014）：牛油底料与清油底料的差异性挥发性成分，适合做"换油/换配方"前后的对照。
- **优化法**（DOC-042）：糍粑辣椒 / 麻椒 / 复合香料为关键变量，响应面法多因素优化——解决"配方层面怎么把风味做稳"，不是货架期问题。

## 五、判定口径

| 情形 | 如何处理 |
|---|---|
| 有企业内控的"特征成分保留率"线 | 按内控线判，写明文件编号、取样时点、检测方法 |
| 无内控 | **输出"限值未核定（不判定）"**，不得自拟"香气保留率 ≥X%"这种线 |
| 只有酸价/过氧化值 | 用它们做**代理判定**，并按 DBS50/022（≤4.0 / ≤0.25）、GB 10146（原料 ≤2.5 / ≤0.20）、Q/NHTY 0019S（油膏包 ≤3 / ≤0.25）分别对照，写明用的是哪一档 |
| 看趋势而非看限值 | 用 DOC-019 那种逐点时序列判"是否进入氧化加速段"，与跨批次 SPC 基线分开说 |

**没有任何国家标准给"风味稳定性"或"香气保留率"设限量**：GB/T 45662-2025 不设酸价与过氧化值，GB 31644-2018 无理化指标。**因此这条只能靠企业内控 + 趋势判定，不能引国标硬判。**

## 六、缺口

1. 16 种关键成分的实测含量（无 GC-MS 数据，只有文献名单）。
2. 出厂时的基线指纹（无"0 天"取样）。
3. "香气保留率"的内控线（无文件）。
4. 消费者端"不香"的主观阈值与仪器指标的对应关系（无感官评价数据）。
